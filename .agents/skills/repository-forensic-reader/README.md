# Repository Forensic Reader

مهارة لفحص مستودع برمجي مرتبط أو مشارك تلقائياً، بما في ذلك مستودعات GitHub والمجلدات المحلية والملفات المضغوطة.

## المحتويات

- `SKILL.md`: ملف المهارة الأساسي.

## الاستخدام

1. أضف مجلد `repository-forensic-reader` إلى مكان المهارات الذي تدعمه المنصة التي تستخدمها، أو ارفع ملف `SKILL.md` إلى نظام المهارات.
2. اربط النموذج بمستودع GitHub، أو شارك رابط المستودع، أو أرفق ملف ZIP.
3. فعّل المهارة واطلب فحص المستودع. صُممت التعليمات لاكتشاف المصدر المتاح تلقائياً دون مطالبتك بتكرار اسمه.

## ملاحظة مهمة

قد تختلف قدرة النموذج على قراءة الأرشيفات والمستودعات الخاصة بحسب أدواته وصلاحياته. المهارة تفرض عليه تجربة مسارات الوصول المتاحة وتوثيق ما تعذر الوصول إليه، لكنها لا تمنح صلاحيات GitHub أو أدوات استخراج غير موجودة في المنصة.
