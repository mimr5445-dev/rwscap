# ◈ صناعة الالتزام (`commit-craft`)

> مهارة عربية من حزمة «مهارات 2» · المعرّف الأصلي: `engineering__commit-craft__skills__commit-craft`

## Hard Rules
- Never blindly commit stray temp artifacts, `.env`, or secrets.
- Group commits logically (e.g., skills & blueprint commit, codebase upgrades + tests commit, docs polish commit).
- Every commit must compile and pass tests on its own.
- Clear subject (≤72 chars) describing intent; body explains *why*.
