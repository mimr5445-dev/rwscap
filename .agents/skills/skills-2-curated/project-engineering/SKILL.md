## Delivery Loop Contract
`Observe → Choose → Act → Verify → Record → Repeat-or-Stop`
- Every delivery goal requires a machine-checkable acceptance criterion (e.g., command exiting `0`).
- Route each task to ONE specialist skill rather than running all skills blindly.
- Never close an iteration with unverified tasks.
