# ◈ صقل الملف README (`readme-polish`)

> مهارة عربية من حزمة «مهارات 2» · المعرّف الأصلي: `engineering__readme-polish`

## Workflow
1. **15-Second Skim Test**: First screen states value in one sentence; copy-pasteable install/run command within first 40 lines; answers What, Why, and How.
2. **Fact Check**: Verify every version, script, feature, test count, and file link against the actual repository — zero invented badges or dead links.
3. **Order**: Hero (title, 1-sentence value, concise nav) → Quickstart → Features & Architecture (Mermaid ≤ 7 nodes) → Skills System Overview → Scripts & Testing → Limits.
4. **Explicit ASCII anchors** (`<a id="..."></a>`) before Arabic/non-ASCII headings for reliable GitHub navigation.
