# ◈ ضمان جودة أولي (`senior-qa`)

> مهارة عربية من حزمة «مهارات 2» · المعرّف الأصلي: `engineering-team__skills__senior-qa`

## QA Automation & Verification Standards
- **Test Pyramid**: Fast Vitest unit tests covering pure timeline, timecode, renderer math, filter string synthesis, waveform generation, and clip operations (`split`, `trim`, `delete`, `duplicate`).
- **Accessible Queries**: Prefer role/label-based interaction tests over brittle internal CSS selectors.
- **Release Gate**: Never mark a task complete until `npm test`, `npm run typecheck`, and `npm run build` all exit 0 with fresh output.
