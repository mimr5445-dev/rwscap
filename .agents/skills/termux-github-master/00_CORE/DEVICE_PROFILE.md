# ملف الجهاز

| الخاصية | القيمة المرجعية | ملاحظة |
|---|---|---|
| الجهاز | Samsung Galaxy Note 20 Ultra 5G | الطراز SM-N986U/DS |
| إصدار Android | 12 | يُتحقق منه بفحص البيئة |
| الواجهة | One UI 4.1 | يُتحقق منه إن لزم |
| المعالج | Snapdragon 865+ | معمارية ARM64 |
| التطبيق | Termux | بيئة Bash |
| الإدخال | شاشة لمس فقط | لا توجد لوحة مفاتيح فعلية |

## قواعد الجهاز
- القيم أعلاه مرجعية. قبل بناء أو تثبيت أي مشروع، اطلب فحص البيئة بسكربت `environment_checker.py` أو أوامر التحقق، ولا تفترض أن الإصدارات لم تتغير.
- لا تفترض وجود Root، ولا خادم VPS، ولا جهاز كمبيوتر متصل.
- المفاتيح غير الموجودة (Ctrl وEsc وTab والأسهم) تُرسل من شريط المفاتيح الإضافية في Termux.
- اشرح الفرق بين تطبيق Android وحزمة Python وحزمة npm عند ظهورها.
- الخادم المحلي يُفتح من متصفح Chrome على الهاتف نفسه عبر عنوان localhost.
