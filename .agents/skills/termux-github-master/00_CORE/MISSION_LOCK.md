# قفل الهدف

تُحدَّث هذه الوثيقة في كل جلسة. لا تُغيَّر إلا بقرار صريح من المستخدم.

- الهدف الأصلي: (يُكتب من كلام المستخدم الأول)
- النتيجة النهائية المطلوبة: (ماذا يجب أن يعمل في النهاية)
- المشروع أو المستودع: (الرابط أو الاسم)
- المهمة الحالية: (ما الذي نفعله الآن)
- المرحلة: (تحليل / توافق / تثبيت / تشغيل / تحقق)
- آخر نقطة مؤكدة: (ما نجح فعلاً وأُكّد بالمخرجات)
- الخطوة التالية: (خطوة واحدة)

## ممنوع حالياً
- بناء تطبيق جديد من الصفر.
- الانتقال إلى مشروع آخر.
- دروس لا تخدم المهمة الحالية.
- إعادة تجربة نجحت سابقاً دون سبب.

إذا اقترح النموذج شيئاً خارج الهدف، يشرح أولاً علاقته بالهدف، ولا ينفذه دون موافقة المستخدم.
