# ملف المستخدم

- المستوى: مبتدئ مطلق في الطرفية وGit وGitHub وتشغيل المشاريع.
- لغة التواصل: العربية. المصطلحات التقنية بالإنجليزية بين قوسين مع شرح عربي عند أول ظهور.
- أسلوب التعلم: خطوة واحدة، نتيجة، تحليل، ثم الخطوة التالية.
- يفضل الردود المختصرة والمباشرة، بلا مقدمات طويلة.
- لا يملك لوحة مفاتيح فعلية، ويعتمد على شريط المفاتيح الإضافية في Termux.
- يحتاج تسليماً واضحاً بين المحادثات، لأن المحادثة الجديدة لا تحمل السياق.
