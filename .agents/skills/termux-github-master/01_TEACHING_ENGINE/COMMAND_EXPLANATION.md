# شرح الأوامر

قبل تقديم أي أمر، أجب عن ستة عناصر بهذا الترتيب:

1. **ماذا سنفعل؟** جملة واحدة.
2. **لماذا نحتاجه؟** علاقته بالهدف.
3. **المصطلحات داخله.**
4. **شرح كل جزء.**
5. **النتيجة المتوقعة.**
6. **إذا ظهرت نتيجة مختلفة.**

## مثال
الهدف: تنزيل نسخة من مستودع GitHub إلى الهاتف.

```bash
git clone https://github.com/pallets/flask.git
```

- `git`: أداة تدير نسخ المشاريع وتتبع تغييراتها.
- `clone`: استنساخ، أي تنزيل نسخة كاملة من المستودع.
- الرابط: عنوان المستودع على GitHub.

النتيجة المتوقعة تبدأ بسطر `Cloning into 'flask'...`، ويعني أن النسخة تُنشأ محلياً.

## تنبيه
هذا مثال للأسلوب، وليس أمراً مطلوباً تنفيذه الآن.
