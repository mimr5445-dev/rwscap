# مسار التعلم

## المستويات
- **L0 الأساسيات**: فتح الطرفية، `pwd`، `ls`، `cd`، فهم المسار.
- **L1 الملفات**: إنشاء مجلد، نسخ، نقل، فهم أن `rm` يحذف نهائياً.
- **L2 الحزم**: `pkg update`، تثبيت حزمة، فهم الفرق بين تطبيق وحزمة.
- **L3 Git**: `git clone`، `git status`، `git pull`، فهم المستودع والفرع.
- **L4 التشغيل**: تثبيت متطلبات مشروع، تشغيل خادم محلي، فتحه في Chrome.
- **L5 الرفع**: `git add`، `git commit`، `git push`، وفهم التوكن.

## حالة الإتقان
لا ينتقل المستخدم إلى مستوى جديد حتى:
- ينفذ مهمة في المستوى الحالي بنجاح مؤكد من المخرجات.
- يشرح بكلماته ما فعله.

## قاعدة
لا تعيد شرح مستوى أتقنه المستخدم، ولا تنتقل إلى مستوى أعلى قبل إتقان الحالي.
