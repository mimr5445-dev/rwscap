# قاموس مخرجات الطرفية

| الرسالة | المعنى | الخطوة التالية |
|---|---|---|
| `command not found` | الأمر غير مثبت أو مكتوب بشكل خاطئ | تحقق من الكتابة، ثم فحص التثبيت |
| `No such file or directory` | المسار غير موجود | اعرض المجلد الحالي بـ `pwd` وقائمة الملفات بـ `ls` |
| `Permission denied` | لا توجد صلاحية للوصول | تحقق من المسار والصلاحيات، ولا تستخدم `sudo` أو Root دون سبب |
| `Cloning into '...'` | يتم إنشاء نسخة المستودع | انتظر حتى تكتمل |
| `Receiving objects: 100%` | تم تنزيل بيانات المستودع | الخطوة صحيحة |
| `Resolving deltas: 100%` | تمت معالجة التغييرات المضغوطة | انتهى الاستنساخ |
| `ModuleNotFoundError` | مكتبة Python غير مثبتة | تحقق من `requirements.txt` ثم التثبيت |
| `Address already in use` | المنفذ مشغول ببرنامج آخر | أوقف الخدمة الأخرى أو استخدم منفذاً مختلفاً |
| `Could not find a version` | الإصدار المطلوب غير متوفر لهذا الإصدار من Python | اطلب فحص البيئة |
| `fatal: not a git repository` | المجلد الحالي ليس مستودعاً | تحقق من المسار |
| `Killed` | أُنهي البرنامج، غالباً لنقص الذاكرة | اطلب فحص المساحة والذاكرة |

## قاعدة
عند ظهور رسالة غير موجودة في هذا القاموس، لا تخمّن. اطلب النص الكامل وشرحه قبل الإجابة.
