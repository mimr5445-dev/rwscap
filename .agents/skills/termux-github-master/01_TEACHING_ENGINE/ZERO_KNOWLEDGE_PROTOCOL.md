# بروتوكول الصفر المطلق

افترض أن المستخدم لا يعرف هذه المفاهيم. اشرح كل مفهوم عند ظهوره لأول مرة في المحادثة.

## المفاهيم الأساسية
- **الطرفية (Terminal)**: نافذة نصية تكتب فيها أوامر بدلاً من النقر على الأيقونات.
- **الأمر (Command)**: تعليمة نصية تكتبها ثم تضغط Enter لينفذها البرنامج.
- **المجلد (Folder/Directory)**: حاوية للملفات، وقد يحتوي مجلدات أخرى.
- **الملف (File)**: وحدة بيانات لها اسم ونوع.
- **المسار (Path)**: عنوان الملف أو المجلد داخل النظام، مثل `~/flask`.
- **المجلد الرئيسي (Home, `~`)**: المجلد الخاص بك داخل Termux.
- **الحزمة (Package)**: برنامج أو مكتبة جاهزة يمكن تثبيتها.
- **التثبيت (Install)**: إضافة برنامج أو حزمة إلى النظام.
- **الاعتماديات (Dependencies)**: الحزم التي يحتاجها المشروع ليعمل.
- **المستودع (Repository, repo)**: مجلد مشروع مخزن على GitHub مع سجل تغييراته.
- **Git**: أداة على هاتفك تتتبع التغييرات في المشروع.
- **GitHub**: موقع يستضيف المستودعات، ويستخدم Git.
- **الاستنساخ (Clone)**: تنزيل نسخة كاملة من المستودع إلى جهازك.
- **الخادم المحلي (Local server)**: برنامج يعمل على هاتفك ويعرض موقعاً أو تطبيقاً.
- **المنفذ (Port)**: رقم يحدد أي خدمة تعمل على الجهاز، مثل `8000`.
- **localhost**: عنوان يعني "هذا الجهاز نفسه".
- **README**: ملف تعليمات يكتبه صاحب المشروع.
- **requirements.txt**: ملف يسرد حزم Python التي يحتاجها المشروع.
- **البناء (Build)**: تحويل الكود إلى ملف جاهز للتشغيل أو التثبيت، مثل APK.

## قواعد الشرح
- عند ظهور مصطلح جديد: اكتب الإنجليزية بين قوسين، ثم شرحاً عربياً قصيراً.
- إذا عاد المصطلح بمعنى مختلف في سياق آخر، اشرح الفرق.
- لا تفترض أن المستخدم حفظ المصطلح. أعد تعريفه باختصار عند الحاجة.
- لا تستخدم اختصاراً قبل أن تشرحه.
