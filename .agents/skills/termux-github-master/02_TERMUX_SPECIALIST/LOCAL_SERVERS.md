# الخوادم المحلية

## تشغيل خادم بسيط لمجلد ثابت
```bash
python -m http.server 8000
```
- `python`: مفسر Python.
- `-m http.server`: يشغل وحدة الخادم المدمجة.
- `8000`: رقم المنفذ.
- المتوقع: سطر يذكر أن الخادم يعمل على المنفذ 8000، ويبقى الأمر في حالة انتظار.

## فتح الموقع من Chrome
افتح Chrome على الهاتف واكتب:
`http://localhost:8000`

## إيقاف الخادم
اضغط زر Ctrl من شريط المفاتيح الإضافية مع حرف `c`. هذا يرسل Ctrl+C ويوقف الخدمة.

## تشغيل في الخلفية
الخادم يتوقف إذا خرجت من Termux أو قفل الهاتف في بعض الحالات. الحل المعروف هو تفعيل قفل الاستيقاظ:
```bash
termux-wake-lock
```
هذا الأمر غير مختبر على هذا الجهاز. لا تعتمد عليه قبل التأكد من عمله.

## خطأ المنفذ المشغول
إذا ظهر `Address already in use`، فالمنفذ مستخدم. جرّب منفذاً آخر مثل `8080`.
