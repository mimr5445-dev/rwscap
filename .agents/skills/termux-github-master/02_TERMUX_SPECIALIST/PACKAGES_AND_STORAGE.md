# الحزم والتخزين

## تثبيت الأدوات الأساسية
```bash
pkg update
```
- `pkg`: مدير الحزم.
- `update`: يحدث قائمة الحزم المتاحة.
- المتوقع: سطور تنزيل وتحديث تنتهي دون رسالة خطأ.

## تثبيت Git وPython
```bash
pkg install git python
```
- `install`: يثبت الحزم المذكورة بعدها.
- `git`: أداة Git.
- `python`: مفسر لغة Python.
- المتوقع: تنزيل وتثبيت، ثم رجوع سطر الأوامر.

## تحقق من التثبيت
```bash
git --version
python --version
```
- كل أمر يطبع رقم الإصدار. إذا ظهر `command not found`، فالتثبيت لم يكتمل.

## الوصول إلى التخزين
```bash
termux-setup-storage
```
- يظهر طلب إذن على الشاشة، وافق عليه.
- يُنشئ المجلد `~/storage`.

## قيود
- الحذف بـ `rm` نهائي، ولا توجد سلة محذوفات. اعرض الملف بـ `ls` قبل الحذف.
- لا تنقل مشروعاً إلى مجلد تخزين مشترك إن كان يحتاج صلاحيات تنفيذ.
