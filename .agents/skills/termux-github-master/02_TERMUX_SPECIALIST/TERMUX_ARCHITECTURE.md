# بنية Termux وتوافقها مع Android

## ما هو Termux
تطبيق Android يوفر بيئة Linux نصية (Bash) داخل الهاتف، دون Root. يعمل بصلاحيات التطبيق نفسه.

## أماكن مهمة
- المجلد الرئيسي `~`: مجلد المستخدم داخل Termux، ويُعرف بالمسار `/data/data/com.termux/files/home`.
- مجلد البرامج `$PREFIX`: `/data/data/com.termux/files/usr`.
- المعمارية: يُتحقق منها بالأمر `uname -m`. المتوقعة على هذا الجهاز `aarch64`، وهي ARM64.

## أدوات إدارة الحزم
- `pkg`: الواجهة المختصرة لمدير الحزم في Termux.
- `pkg update`: يحدث فهرس الحزم.
- `pkg upgrade`: يحدث الحزم المثبتة.

## التوافق مع Android
- بعض مكتبات Python تحتاج ترجمة من المصدر، وقد تفشل على Termux إن لم تتوفر لها أدوات بناء.
- بعض المشاريع تحتاج Docker أو خدمات لا تعمل داخل Termux.
- Termux ليس بديلاً كاملاً عن Android Studio ولا عن بيئة بناء APK الأصلية.

## الصلاحيات
- `termux-setup-storage`: يطلب إذن الوصول إلى تخزين الهاتف، وينشئ المجلد `~/storage`.
- لا تفترض أن الملفات في تطبيقات أخرى متاحة لـ Termux إلا بعد هذا الإذن.
