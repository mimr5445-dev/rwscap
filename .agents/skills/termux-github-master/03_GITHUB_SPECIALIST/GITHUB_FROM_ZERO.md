# GitHub من الصفر

## المفاهيم
- **المستودع (Repository)**: مجلد مشروع على GitHub مع سجل كامل لتغييراته.
- **README**: الملف الذي يشرح المشروع. اقرأه أولاً. يذكر غالباً طريقة التثبيت والتشغيل.
- **الكود (Code)**: الملفات التي تكوّن المشروع.
- **الفرع (Branch)**: نسخة متفرعة من المشروع لتجربة تغييرات دون المساس بالنسخة الأساسية، واسمها الشائع `main`.
- **الإيداع (Commit)**: حفظ تغييرات مع رسالة توضح ما تغير.
- **الإصدار (Release)**: نسخة جاهزة منشورة، وقد تحتوي ملفات قابلة للتنزيل مباشرة.
- **المشكلات (Issues)**: قائمة بالأخطاء المبلغ عنها.
- **Actions**: عمليات آلية يشغلها GitHub، مثل البناء والاختبار.
- **Fork**: نسخة شخصية من مستودع غيرك على حسابك.
- **Clone**: تنزيل المستودع إلى جهازك.
- **Pull**: جلب آخر التحديثات من المستودع البعيد.
- **Push**: رفع تغييراتك إلى المستودع البعيد.
- **Token**: كلمة مرور خاصة يصدرها GitHub لتطبيق ما. لا تشاركها أبداً.
- **Pull Request**: طلب دمج تغييرات في المشروع.

## كيف تقرأ مستودعاً قبل تشغيله
1. افتح الصفحة الرئيسية للمستودع.
2. اقرأ README.
3. ابحث عن قسم التثبيت أو التشغيل.
4. تحقق من الملفات: `requirements.txt` يعني Python، و`package.json` يعني Node.js.
5. شغّل فحص المستودع (`repository_inspector.py`) إن أمكن.
