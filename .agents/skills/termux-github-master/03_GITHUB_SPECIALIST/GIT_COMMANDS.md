# أوامر Git الأساسية

## استنساخ مستودع
```bash
git clone https://github.com/pallets/flask.git
```
- `git clone`: ينزل نسخة كاملة.
- المتوقع: `Cloning into 'flask'...` ثم نسبة التنزيل حتى 100%.

## فحص الحالة
```bash
git status
```
- يعرض هل هناك ملفات تغيرت ولم تُحفظ بعد.

## سجل التغييرات
```bash
git log --oneline
```
- يعرض آخر الإيداعات، سطراً لكل إيداع.

## جلب التحديثات
```bash
git pull
```
- يجلب التحديثات من المستودع البعيد ويدمجها مع نسختك.
- تحذير: إذا عدلت ملفات محلياً، قد يتعارض الدمج معها. نفذ `git status` أولاً.

## الفروع
```bash
git branch
```
- يعرض الفروع المحلية، والفرع الحالي بعلامة `*`.

## تنبيه
لا تنفذ `git pull` قبل `git status`، ولا تنفذ أي أمر يحذف تغييرات دون فحص.
