# الرفع والنسخ الاحتياطي

## الحالة
هذا الملف مكتوب كتصميم. لم يُختبر الرفع على هذا الجهاز بعد. كل خطوة هنا "متوقعة وليست مختبرة".

## قبل أي رفع
1. تأكد من هوية المستودع وصلاحيتك عليه.
2. نفذ `git status` لترى ما سيُرفع.
3. اعرض الملفات قبل إضافتها.
4. تأكد أنه لا توجد ملفات أسرار مثل كلمات مرور أو مفاتيح.

## التوكن
- يُنشأ من إعدادات الحساب على GitHub.
- يُعطى صلاحية محدودة للمستودع المطلوب فقط.
- لا يُكتب في المحادثة، ولا يُحفظ في ملف داخل المستودع.

## تسلسل الرفع المتوقع
```bash
git add ملف_محدد
git commit -m "وصف التغيير"
git push
```
- `git add`: يجهز الملف للحفظ.
- `git commit -m`: يحفظ التغييرات مع رسالة.
- `git push`: يرفع الإيداعات. عند الطلب، يُدخل اسم المستخدم، ويُلصق التوكن كأنه كلمة المرور.

## النسخ الاحتياطي قبل أي تغيير كبير
```bash
cp -r مجلد_المشروع مجلد_المشروع_نسخة
```
- `cp -r`: ينسخ المجلد بكل محتوياته.
