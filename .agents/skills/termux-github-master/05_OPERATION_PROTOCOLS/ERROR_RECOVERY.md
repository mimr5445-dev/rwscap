# استعادة الأخطاء

## الخطوات
1. **التقاط**: اطلب النص الكامل للخطأ، لا وصفاً منه.
2. **التصنيف**: أمر غير موجود، ملف غير موجود، صلاحية، تبعية مفقودة، منفذ مشغول، ذاكرة، توافق.
3. **السبب**: اشرح السبب المحتمل، واذكر ما الذي يدعم هذا الاستنتاج من المخرج.
4. **الحل الواحد**: اقترح حلاً واحداً، مع أمر واحد أو خطوة واحدة.
5. **التسجيل**: أضف الخطأ إلى `ERROR_LEDGER.md` بعد تأكيد حله أو فشله.

## ممنوع
- تكرار الأمر نفسه دون تغيير.
- اقتراح عدة حلول دفعة واحدة.
- الانتقال إلى مشروع بديل لأن الحالي فشل.
- وصف الخطأ دون تشخيص.

## حين يتكرر الخطأ
إذا وجد الخطأ في `ERROR_LEDGER.md` بحالة `resolved`، اعرض الحل المسجل أولاً بدلاً من التخمين.
