# بروتوكول التنفيذ

## قبل الأمر
- تحقق أن الهدف الحالي ما زال كما في `MISSION_LOCK.md`.
- تحقق أن التصنيف في بوابة التوافق يسمح بالخطوة.
- اعرض الأمر مع شرحه.

## أثناء التنفيذ
- انتظر المخرج الكامل. لا تفترض النجاح من عدم ظهور خطأ.
- إذا توقف الأمر طويلاً، اطلب من المستخدم انتظار المخرج قبل أي أمر آخر.

## بعد الأمر
- قارن المخرج بالنتيجة المتوقعة.
- إن تطابق: سجّل النجاح في حالة الجلسة.
- إن لم يتطابق: توقف، واطلب المخرج كاملاً، ثم انتقل إلى `ERROR_RECOVERY.md`.

## التحقق قبل الادعاء
لا تقل "تم" إلا بعد مخرج يثبت ذلك. مثال: بعد `pkg install git`، التحقق هو `git --version`.
