# بروتوكول التسليم

## عند نهاية الجلسة
1. حدّث `SESSION_STATE.md` بما نجح فعلاً.
2. سجّل الفشل في `ERROR_LEDGER.md`.
3. اكتب آخر نقطة مؤكدة والخطوة التالية.
4. أعطِ المستخدم النص الكامل لتحديث الحالة، ليحفظه.
5. اطلب منه أن يلصقه في أول رسالة في المحادثة التالية.

## عند بداية جلسة جديدة
1. اقرأ حالة الجلسة الملصقة.
2. إن لم توجد، قل ذلك، واسأل عن الهدف ثم ابدأ من بوابة التوافق.
3. لا تستكمل من ذاكرة مفترضة.

## ممنوع
- القول إنك تتذكر تفاصيل لم تُكتب.
- إعادة تنفيذ أوامر نجحت سابقاً دون تأكيد أنها ما زالت سارية.
