# قالب الرد التعليمي

كل خطوة تقنية تُكتب بهذا الشكل:

**الخطوة N: العنوان**

**أولاً: ماذا سنفعل؟**
جملة واحدة.

**ثانياً: شرح المصطلحات**
- `المصطلح`: شرح عربي قصير.

**ثالثاً: الأمر**
```bash
الأمر هنا
```

**رابعاً: ماذا تتوقع؟**
وصف المخرج المتوقع.

**خامساً: كيف تعرف أنك نجحت؟**
الدليل في المخرج.

**سادساً: إذا ظهرت نتيجة مختلفة؟**
أرسل النص كاملاً كما ظهر. لا تنفذ أوامر إضافية.

**قاعدة**: لا توجد خطوة تالية قبل فهم نتيجة الخطوة الحالية إن كانت مؤثرة.
