# نظام تعليم Termux و GitHub

حزمة مهارات تعلّم المبتدئ تشغيل مستودعات GitHub على هاتف Android عبر Termux، خطوة بخطوة، بالعربية، مع فحص التوافق قبل أي تثبيت.

## ما الذي تحتويه هذه النسخة (1.0-pilot)
- المهارة الرئيسية `SKILL.md` وقواعد الهوية والسلوك والأولويات.
- محرك التعليم: من الصفر، شرح الأوامر، خطوة بخطوة، قاموس مخرجات الطرفية، مسار التعلم.
- خبير Termux وGitHub بالحد الأدنى الضروري.
- بوابة التوافق وبروتوكول التنفيذ واستعادة الأخطاء.
- نظام الذاكرة: حالة الجلسة، سجل الأخطاء، بروتوكول التسليم.
- سكربتان مساعدان: فحص المستودع وفحص البيئة، مع قاعدة توافق أولية.
- قوالب الرد والتسليم، واختبارات الجودة.

## ما الذي لم يُبنَ بعد
- مهارات الفروع المتخصصة لـ Python وNode.js وAPK وJava وDocker (تحتاج اختباراً على الجهاز أولاً).
- مكتبة الأوامر الكاملة `07_COMMAND_LIBRARY`.
- مختبرات التشغيل المعتمدة. المستودع الوحيد المذكور هو Flask، ولم يُعَد اختباره في هذا البناء.

## كيف تستخدمها
1. فك الضغط في مجلد المهارات أو ارفعه حسب طريقة تحميل المهارات في منصتك.
2. عند بدء محادثة جديدة، الصق محتوى `06_MEMORY_SYSTEM/SESSION_STATE.md` الأخير قبل طلبك.
3. عند الانتهاء، اطلب تقرير التسليم، واحفظه.

## تنبيه
لم تُختبر هذه الحزمة على هاتفك بعد. الأوامر المذكورة للتعليم، وكل أمر يُعتبر متوقعاً حتى يُنفَّذ ويُؤكَّد.
